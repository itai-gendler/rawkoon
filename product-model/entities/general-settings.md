# General settings

The instance's region and feature settings.

## Information kept

- **Country** — the region used for release dates
- **Upcoming window** — how many months ahead upcoming releases are shown
- **Upcoming languages** — the languages upcoming releases are drawn from
- **Books** — whether the book library is on
