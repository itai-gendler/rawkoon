# Watchlist item

A movie or show a person wants to watch, kept on their own watchlist.

## Information kept

- **Title** — the title
- **Kind** — movie or show
- **Poster** — the poster
- **Overview** — the synopsis
- **Year** — the release year
- **Rating** — the catalog rating
- **Release date** — for a movie, its release date
- **Reminder sent** — the release date a day-before reminder was already sent for
- **Added** — when it was added
